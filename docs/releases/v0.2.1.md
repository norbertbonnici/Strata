# Strata 0.2.1 🔎

**YARA scanning**, plus the results of a full code review of the source tree:
18 fixes, several of them evidence-integrity or detection-accuracy bugs. If you
use carving, multi-host cases, IOC matching or E01 macOS images, this is a
recommended update.

## 🧬 New: YARA scanning

- Point Strata at your own ruleset (`.yar` / `.yara`) and scan the evidence —
  the active host or every host in the case. Rules compile once up front, so a
  broken ruleset fails before anything is extracted.
- Size and file-count caps keep a scan bounded; matches persist with the case
  and appear in a new **YARA Matches** view.
- A match becomes a finding, deliberately without an ATT&CK technique or a
  timestamp: it shows the content is present, not that it ran.
- Built on upstream YARA 4.5.8, bundled with the app like the rest of the
  toolchain.

## 🔒 Evidence integrity

- **Saving a carved file could write the wrong host's bytes** in a case with
  more than one macOS E01. Fixed.
- **Switching cases with File ▸ Open Recent leaked the previous case's
  cross-host findings** into the new case's findings, report and AI-summary
  input. Fixed; closing a case now also forgets any FileVault password.
- **macOS E01 images can now be verified with ewfverify.** Their embedded
  acquisition hashes were previously impossible to verify.
- **PDF carving no longer swallows the files that follow a PDF.**
- A failed cloud AI summary is now recorded in the chain of custody, since
  finding summaries may already have left the machine.

## 🎯 Detection accuracy

- **Command-line detections now see the real text.** Event data arrived
  XML-escaped (`2&gt;&amp;1` instead of `2>&1`), so some Impacket signatures
  could never fire and IOCs containing `&` never matched.
- **IP indicators match whole addresses only** — `10.0.0.1` no longer matches
  `10.0.0.15`.
- **Far fewer credential-reuse false positives** on Linux: only human accounts
  and real logins count, not the service accounts every install shares.
- Carved JPEGs are no longer truncated to their embedded thumbnail.

## 🧱 Fixes & polish

- FileVault unlock now keeps your existing results and re-runs the analyzers.
- Running analyzers can no longer undo a parse or scan that finished meanwhile.
- "Run analyzers" on the Kill Chain tab works for Linux and macOS cases.
- Faster event-log parsing on large cases.
- A crafted property-list file can no longer hang ingest.
