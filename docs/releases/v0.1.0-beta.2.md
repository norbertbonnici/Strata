# Strata 0.1.0 — Beta 2 🎉

Second beta. Highlights since beta 1: an **iOS viewer companion**, a
**volume-grouped Evidence tree**, a big **performance pass**, and a long list of
correctness/UX fixes from a full code review.

## New

- 📱 **iOS viewer** — open a `.strata` case on iPhone/iPad and review the
  overview, timeline, events, kill chain, lateral movement, filesystem, and IOCs.
  Read-only: ingest a case on macOS, then open it on iOS. *(Build the iOS target
  from source — the download below is the macOS app.)*
- 💽 **Evidence tree grouped by volume** — each filesystem (EFI/FAT, the main
  NTFS volume, recovery NTFS, …) is its own node, so per-volume metadata
  (`$MFT`, `$LogFile`, `$BadClus`, …) no longer looks like duplicates.
- **"Hide slack" toggle** on the Evidence tab.

## Improved

- **Much faster on large cases** — derived data is rolled up and cached, and the
  heavy work is computed off the render path, eliminating repeated main-thread
  sorts on million-row timelines and event logs.
- Recent cases use security-scoped bookmarks; the force-directed lateral layout
  is capped on very large graphs; accessibility and contrast improvements.

## Fixed

- Timeline histogram drag-to-select accuracy; sortable + chronological IOC table;
  dismissable kill-chain inspector; the Evidence tree no longer drops deleted-vs-
  live same-path entries (or renders empty); plus many iOS viewer fixes
  (filesystem navigation, lazy/paged lists, UTC timestamps, Sysmon filter).

## Requirements

- **Apple Silicon Mac, macOS 14 (Sonoma) or later** for the macOS app.
- Grant **Full Disk Access** on first launch (System Settings ▸ Privacy &
  Security) — Strata reads raw disk images and can't be sandboxed.

## Install

1. Download `Strata-0.1.0-beta.2.dmg` below.
2. Open it and drag **Strata** into **Applications**.
3. Launch, grant **Full Disk Access**, reopen.

Developer ID-signed and notarized, so it opens without Gatekeeper warnings.
