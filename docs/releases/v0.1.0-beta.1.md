# Strata 0.1.0 — First Beta 🎉

Strata is a native macOS DFIR triage tool. Point it at a Windows disk image or a
KAPE collection and it enumerates the file system, builds a MACB timeline, parses
Windows event logs and registry hives, and surfaces attacker activity across
ATT&CK-tagged analyzers, a Cyber Kill Chain view, and an interactive
lateral-movement graph.

This is the **first public beta** — the pipeline works end to end, but expect
rough edges. Bug reports and feedback are very welcome.

## Highlights

- **Evidence ingestion** — E01/EX01/S01, VHD/VHDX (KAPE `--vhd`), and raw `dd`
  images via The Sleuth Kit; **loose KAPE/triage folders** are read directly off
  disk (no image container required).
- **Self-contained** — TSK and the libyal tools (`libevtx`, `libregf`) are built
  from source and vendored. **No Homebrew or other runtime dependencies.**
- **Multi-host cases** — a `.strata` bundle holds one or more hosts, with a
  recent-cases list.
- **MACB timeline** with a drag-to-select histogram (handles million-row
  datasets) and **gap analysis** that surfaces quiet periods and activity bursts.
- **Windows artifacts** — event logs (`.evtx`) and registry hives parsed into a
  typed **host profile** (hostname, domain, OS build, install/shutdown times,
  primary user, time zone, IPs).
- **15 detection analyzers** emitting ATT&CK-tagged findings into the kill chain:
  logon failures/success, PowerShell, process creation, service install,
  scheduled tasks, log clearing, persistence files, Run keys, services-registry
  persistence, USB history, Impacket-style remote exec, RMM tooling, password
  spray, and credential pivots.
- **IOC matching** — paste IPs, domains, URLs, and hashes; matched across logon
  fields and timeline/event data.
- **Interactive lateral-movement graph** — pan, zoom, drag nodes, and an optional
  force-directed layout; built from remote logon events (Security 4624/4625).

## Requirements

- **Apple Silicon Mac** — this beta is arm64-only.
- **macOS 14 (Sonoma) or later.**
- **Full Disk Access** — grant on first launch under
  System Settings ▸ Privacy & Security ▸ Full Disk Access. Strata reads raw disk
  images, so it can't be sandboxed.

## Install

1. Download `Strata-0.1.0-beta.1.dmg` below.
2. Open it and drag **Strata** into **Applications**.
3. Launch it, then grant **Full Disk Access** when prompted and reopen.

The app is Developer ID-signed and notarized, so it opens without Gatekeeper
warnings.

## Known limitations

- **Apple Silicon only** for now — Intel support needs a universal build.
- Loose-folder timelines use the collection host's modified/created times; true
  NTFS MACB (via a collected `$MFT`) is planned.
- `$FILE_NAME` timestamps and timestomping detection aren't implemented yet.
- No YARA scanning or known-bad hashing yet.
