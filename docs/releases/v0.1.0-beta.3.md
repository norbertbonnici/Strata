# Strata 0.1.0 — Beta 3 🎉

Third beta — a big one. Validated end-to-end against a **real Ubuntu ext4 VM
image**, which drove a Linux hardening pass; then a large feature build:
**+9 detection analyzers (35 → 44)**, **tiered CTI enrichment**, **Windows
Recycle Bin recovery**, **global search**, **first-class macOS triage**, and
**multi-host correlation**.

## New

- 🔎 **Tiered CTI enrichment** — a **NSRL → MISP / OpenCTI → VirusTotal**
  waterfall that short-circuits on the first definitive verdict (so a known-good
  hash never reaches VirusTotal). Provenance-stamped verdicts, a **known-bad
  hash** tier, per-instance credentials in the **Keychain**, all strictly opt-in
  — nothing leaves the host unless you enable a network tier. Surfaced in the IOC
  tab with a verdict pill.
- 🗑️ **Recycle Bin recovery (Windows)** — parses `$I` index files to recover
  deleted files' original path, size, and deletion time, with a dedicated tab and
  a deletion-burst / staged-exe analyzer (T1070.004).
- 🔭 **Global search** — one query across files, events, registry, timeline, and
  findings, ranked and kind-filterable.
- 🍎 **macOS triage** — LaunchAgents/Daemons persistence (T1543) and the
  LaunchServices download-quarantine store (T1204/T1105), with **Launch Items**
  and **Quarantine** tabs that appear for APFS/HFS+ evidence.
- 🔗 **Multi-host correlation** — flags the same IOC, source IP, or account
  appearing across two or more hosts in a case.
- 🐧 **More Linux parsers** — `lastlog2.db` (modern Ubuntu last-login),
  the `sudo` logfile, and app-server access logs (Rails / puma / Node).

## Detection

**Nine new ATT&CK analyzers** (35 → 44): Credential Dumping (T1003/T1558),
Impact/Destruction (T1485/T1486/T1490/T1561), Lateral-Movement Breadth
(WinRM/WMI/DCOM/admin-share, T1021/T1047), AD Recon (Kerberoast/AS-REP, T1558),
Windows MRU, Linux Anti-Forensics (T1070), Recycle Bin, macOS Persistence, and
macOS Quarantine.

## Improved

- **Linux triage hardened on real evidence** — newly-added artifact types now
  backfill into cases parsed by an earlier build; the timeline defaults to the
  populated bounded sources instead of looking blank; **host IP recovery** on the
  Overview (netplan / ifupdown / journal DHCP lease); and every Linux artifact
  table is now **column-sortable** with filters.
- **Clearer empty states** — Audit / Last Login / Web Logs now explain *why*
  they're empty on a given host (e.g. auditd not installed; `lastlog` empty —
  see Auth & Logins) instead of looking like a parsing failure.

## Fixed

- **Browser history "file is not a database" crash** on Linux images (a
  name-collision `History` file) — now gated on the SQLite magic header.
- A **latent, suite-wide Windows bug**: process-basename matching split on `/`
  only, so backslash image paths (`C:\…\powershell.exe`) never matched — several
  Windows parent/child detections silently never fired on real evidence.

## Requirements

- **Apple Silicon Mac, macOS 14 (Sonoma) or later** for the macOS app.
- Grant **Full Disk Access** on first launch (System Settings ▸ Privacy &
  Security) — Strata reads raw disk images and can't be sandboxed.

## Install

1. Download `Strata-0.1.0-beta.3.dmg` below.
2. Open it and drag **Strata** into **Applications**.
3. Launch, grant **Full Disk Access**, reopen.

Developer ID-signed and notarized, so it opens without Gatekeeper warnings.
