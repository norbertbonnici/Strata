# Strata 0.1.0 — Beta 4 🎉

The biggest release yet, on two fronts: **on-device, sovereign AI case
summaries**, and a **deep macOS triage suite** — the macOS path went from a
handful of artifacts to a full forensic surface that reads APFS content
directly. Plus a whole-codebase **security-hardening** pass against hostile
evidence, big performance gains, and an internal reorg.

## 🧠 New — On-device AI case summaries

- **Executive summary of a case's findings**, written by the model — a factual,
  ATT&CK-aware narrative that walks the incident across the kill chain. Runs
  **entirely on-device** via Apple Intelligence by default; no evidence — and no
  evidence-derived data — leaves the host.
- **Hallucination containment.** Every claim is validated against real evidence:
  the model can only cite findings that exist, phantom citation IDs are stripped,
  invented file paths are flagged, and a claim's severity/phase come from the
  cited findings — not the model. Guided generation constrains the *shape*; this
  constrains the *truth*.
- **Sovereignty is a setting, not a rewrite.** Three tiers run the *same*
  validated pipeline: **On-device** (nothing leaves the host), **Apple Private
  Cloud Compute** (off-device but attested + stateless, no API key), and a
  **third-party cloud** model you credential. Any egress is gated, confirmed,
  clearly labeled, and recorded in the chain of custody — and only finding
  *summaries* are ever sent, never raw evidence or file contents.
- **Scales to large cases.** Findings are aggregated into a deduplicated digest
  and batched to the selected backend's context window — now **configurable from
  the settings sheet** — so a case with tens of thousands of findings still
  summarizes. The model can also call read-only tools to confirm a file or its
  download origin against the real records.
- **Built-in self-eval** (Tools menu): technique recall, confabulation rate, and
  validator-containment numbers over a labeled corpus.

## 🍎 New — macOS triage suite

macOS evidence (APFS / HFS+) now reads **file content directly** (vendored
libfsapfs + a custom `fsapfscat`), unlocking ~20 artifact types — each with a
dedicated tab, a timeline splice where it carries timestamps, and an ATT&CK
analyzer where it's high-signal:

- **Unified Log** — a full `.tracev3` decoder (firehose tracepoints, timesync,
  `.uuidtext`/`dsc` format-string resolution) → sudo / SSH / osascript / Screen
  Sharing / account-creation analyzer.
- **Messages** (`chat.db`) + suspicious-link analyzer, and **Mail** (Envelope
  Index) + inbound-phishing analyzer.
- **KnowledgeC** (app focus / usage → hands-on-keyboard RMM use, T1219), **TCC**
  (privacy/consent grants to non-Apple apps), and **Powerlog** (process
  execution *with PIDs* — execution timing the unified log can miss).
- **Background Task Management** (login items/agents/daemons), **kernel + System
  Extensions**, **launchd persistence** + a **non-launchd persistence sweep**
  (cron, periodic, emond, login/logout hooks, profiles).
- **Download Origins** — the `kMDItemWhereFroms` xattr, recovering provenance
  even when the quarantine flag was stripped — plus the **Quarantine** store and
  **macOS Security** events (Gatekeeper / XProtect / MRT).
- **Network & Devices** (Wi-Fi, DHCP leases, Bluetooth, Time Machine, iOS
  pairings), **QuickLook & Trash**, **Document Versions**, **Notifications**,
  **Install history**, and **Configuration posture** (firewall, screen-lock,
  remote-service enablement, Gatekeeper).
- **FSEvents** change history, **Recent Items**, and a **signature file carver**
  that recovers deleted files from unallocated space — including the sealed
  System snapshot and locked FileVault volumes the filesystem layer won't surface.

## 🔒 Hardening

- **Whole-codebase input-safety audit.** All parser input is adversary-controlled
  (evidence from compromised hosts), so a 48-finding pass hardened the parsers and
  ingest against malformed/malicious data — integer-overflow traps, decompression
  bombs, runaway loop/recursion, scratch-path traversal, descriptor leaks, and
  more.

## ⚡ Improved & Fixed

- **AI summary on big cases** — backend-window-aware batching, a configurable
  context window, and a much clearer error when a backend declines (the real
  cause, not an opaque code).
- **GRDB** pinned to a fixed version (was tracking a moving branch).
- **TSK slack pseudo-entries** no longer trigger spurious ransomware-entropy
  reads or download-provenance xattr reads on case load.
- **Multi-host evidence-tree** crash / corruption fixed.

## 🧱 Under the hood

- Source reorganized by OS family (`Platforms/<Windows|macOS|Linux>/`), the
  6,000-line `AppModel` split into per-concern extensions, **parallelised** case
  load + file carving (sized to performance cores), and SwiftLint + a
  structure-guard CI check.

## Requirements

- **Apple Silicon Mac, macOS 26.5 or later.** (Raised from Sonoma in beta 3 — the
  on-device AI layer links the current FoundationModels framework.) The
  **Apple Private Cloud Compute** summary tier additionally needs **macOS 27**;
  on-device summaries and all other triage run on macOS 26.5.
- Grant **Full Disk Access** on first launch (System Settings ▸ Privacy &
  Security) — Strata reads raw disk images and can't be sandboxed.

## Install

1. Download `Strata-0.1.0-beta.4.dmg` below.
2. Open it and drag **Strata** into **Applications**.
3. Launch, grant **Full Disk Access**, reopen.

Developer ID-signed and notarized, so it opens without Gatekeeper warnings.
