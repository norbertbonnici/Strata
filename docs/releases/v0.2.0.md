# Strata 0.2.0 🛡️

A **security & robustness** release. A full review of the ingest pipeline across
the three OS paths (Windows / Linux / macOS) and the case load/save layer
remediated 26 verified findings, plus a toolchain refresh. Nothing changes about
*what* Strata analyzes — it's a lot harder to fool, crash, or mislead against
hostile evidence, and its forensic-integrity guarantees are tighter.

## 🔒 Forensic integrity & security

- **No more false integrity failures.** Subprocess output is captured with a
  drain-to-EOF runner, so a truncated tool tail can never flip `ewfverify` to a
  false FAILURE or drop an E01's embedded acquisition hashes from the chain of
  custody. A verdict-less run now reads as *inconclusive*, not a failure.
- **FileVault secret off the command line.** The volume password / recovery key
  is handed to the content-extraction tool over stdin instead of the
  world-readable process arguments (visible via `ps`, captured by sysdiagnose).
- **Corrupt ≠ "never parsed".** A cached artifact that exists but won't decode
  (bit-rot, a truncated sync, an older format) is surfaced as a warning banner
  instead of silently showing an empty tab — including the legal-weight custody
  ledger. "No events" and "failed to read the events" are no longer identical.
- **Loose-folder symlink safety.** A KAPE / UAC collection can no longer trick
  the tool into following a symlink out of the evidence set and reading the
  analyst's own machine.
- **One bad file can't sink a whole artifact type.** A single hostile or corrupt
  file in a parse pass is recorded and skipped, instead of aborting the pass and
  discarding everything already parsed.

## 🧱 Robustness

- APFS: empty / sealed volumes are no longer mislabelled FileVault-locked; bare
  containers ingest; the bodyfile read is bounded and tolerant of non-UTF-8
  filenames; several crash traps closed.
- Cases are portable again: a moved or copied `.strata` still extracts APFS
  content, and a case whose source folder is gone keeps its cached findings.
- Sub-second timestamps survive save / reload; case writes are more atomic;
  removing a host can't leave the bundle half-updated.
- Fixed a Linux log classifier that could mistake an unrelated file (e.g. a
  Windows app asset named like a log) for a syslog and re-scan it on every open.
- FileVault unlock now actually re-runs the macOS + browser analyzers.

## 🛠️ Build & toolchain

- All targets on the macOS / iOS 26.6 SDK; the vendored Sleuth Kit + libyal
  tools are bundled into the app automatically; the toolchain builds cleanly from
  source again (refreshed libyal pins + a global pkg-config shim).
